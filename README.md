# Asia-Pacific Digital Health Interoperability Bootcamp 2026 – Book of Proceedings

Sydney, 18–20 October 2026. Session presentations and delegate handouts.

**Website:** https://sscproject.github.io/DHIBSYD2026/

## Folders

- `presentations/` – session slides (PDF)
- `handouts/` – agenda, pre-reads, one-pagers and briefs
- `assets/` – banner image
- `sessions.json` – the list of sessions and handouts shown on the website

## Adding a presentation

Every session in `sessions.json` already has a file name, e.g. `presentations/d1-09-connected-care-ips.pdf`.

1. Rename the speaker's PDF to that file name.
2. Upload it to the `presentations/` folder (on GitHub: **Add file → Upload files**).
3. Commit. The site shows a download button for it within a minute or two.

Until a file is uploaded, the session shows "Coming soon".
